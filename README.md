# 📁 Portal Web de Seguimiento de Proyectos y Descarga de Documentos

Plataforma B2B/B2C en formato portal privado que permite a los clientes consultar el estado de sus expedientes, reparaciones o proyectos, reduciendo llamadas recurrentes.

---

### 🚀 Probador Online (Live Demo)
Prueba la aplicación directamente en tu navegador sin instalar nada:
👉 **[Ver Demostración](https://giodev2104.github.io/Aplicacion-web-de-reserva-de-materiales-y-espacios/)**

---

### 🌟 Características Principales
* **Línea de Tiempo:** Visualización del progreso actual por fases o etapas.
* **Área de Documentación:** Acceso directo a descarga simulada de facturas y contratos en PDF.
* **Canal de Avisos:** Módulo directo de notificaciones del equipo hacia el cliente.

---

### 🛠️ Personalización para Empresas
Este portal se puede **adaptar y personalizar completamente** según la identidad visual, fases de trabajo y requerimientos del cliente.
